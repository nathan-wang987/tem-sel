# 像素守卫 · Pixel Warden

一款可以直接在浏览器里打开就玩的**横版打怪升级**小游戏：
TypeScript 开发，界面用 React，游戏画面用 Canvas 绘制，画面风格是**像素版 3D**
（低分辨率画布 + 透视投影 + 体素方块 + 量化色阶 + 有序抖动）。

```
左键移动 → 二段跳 → 挥剑连击 → 三个技能（旋风斩 / 影袭冲刺 / 生命回复）
→ 打死怪拿经验 → 升级弹三选一 → 一波比一波强的怪潮
```

## 一、怎么玩（30 秒上手）

| 操作 | 按键 |
| --- | --- |
| 左右走动 | `←` `→` 或 `A` `D` |
| 跳跃（空中可再跳一次） | `空格` 或 `↑` `W` |
| 挥剑斩击（三段连击） | `J` `Z` 或**鼠标左键** |
| 旋风斩（原地转一圈砍周围） | `K` 或 `1` |
| 影袭（向前冲刺，冲刺期间不会被打到） | `L` 或 `2` |
| 生命回复 | `H` 或 `3` |
| 暂停 / 继续 | `P` 或 `Esc` |
| 音效开关 | `M` |
| 升级选卡 | 点卡片，或按 `1` `2` `3` |

界面底部会显示每个技能**还剩多少秒**才能再放；血条、经验条、波次、击杀数都在顶部。

### 三种怪物一眼可分

| 怪物 | 外观 | 特点 |
| --- | --- | --- |
| **游荡者**（Grunt） | 橄榄绿、矮胖、黄色大眼 | 普通杂兵，会追着你打，攻守均衡 |
| **刺影**（Assassin） | 猩红细高、尖刺冠 | 伤害极高但很脆；**出手前后仰蓄力约 0.6 秒**，头顶会闪红色感叹号，看准了能躲开，也能一刀打断它的蓄力 |
| **石魔**（Brute） | 灰紫色、又宽又壮、背有石板 | 血量是刺影的 8 倍、走得很慢、打人不疼；带超级护甲，普攻砍不断它的动作 |

## 二、怎么运行

### 方式 1：直接打开（零依赖，最省事）

```
双击 index.html
```

`dist/game.js` 与 `dist/game.css` 已经随仓库提交，所以**不需要 npm install、不需要构建**就能玩。
（用 `file://` 打开时，个别浏览器会禁用 localStorage，此时游戏会自动退回"本次会话内保存"，并在菜单里提示。）

### 方式 2：本地静态服务器（推荐，存档一定可用）

```bash
node tools/serve.mjs        # 打开 http://localhost:5173/
# 或者
npm run serve
```

### 方式 3：开发模式（改代码自动重建）

```bash
npm install          # 只有开发/构建才需要
npm run dev          # 监听 + 起服务
npm run build        # 只构建到 dist/
npm run typecheck    # TypeScript 全量类型检查
npm test             # 引擎 / 会话 / 渲染 / UI 全套测试
```

> 说明：**玩**不需要 Node，只有**改代码 / 跑测试**才需要 `npm install`。

## 五、技术要点

### 1. 像素版 3D 是怎么画出来的

玩法仍然是 2D（x 左右、y 上下），但相机放在玩家后上方并向下俯视，于是每一步都有真实的进深：

1. 每个角色/道具都是若干个**盒子**（`render/models.ts`），盒子 6 个面各带法线；
2. 法线背向相机的面直接剔除；
3. 方向光照射后把亮度**量化到 5 个色阶**（像素画的硬明暗）；
4. 顶点透视投影后**取整吸附到像素网格**（所以边缘是方块状的）；
5. 所有面按"离相机距离"从远到近排序再填充（画家算法），得到正确遮挡；
6. 半透明（冲刺残影、无敌闪烁、远景雾）用 **4x4 Bayer 有序抖动**实现——真实的像素画没有 alpha 混合；
7. 画布本身就固定在 400×225 这样的低分辨率，再用 CSS `image-rendering: pixelated` 放大到全屏。

远山、方形月亮、火把、石柱、棋盘格地面、距离雾、出生光柱、怪物血条、伤害数字都在同一套管线里。

### 2. 时间与暂停

- 逻辑固定 1/60 步长推进（`engine/clock.ts`），物理与伤害判定和刷新率无关；
- 单帧最多补算 5 步、超过 0.2 秒的时间直接丢弃，所以切窗口回来**不会**瞬间刷一堆动作；
- 暂停、结算、升级选卡、阵亡时**完全不喂时间**，累加器也不累加（需求 6 / 8）。

### 3. 长期运行的稳定性

- 怪物、粒子、飘字全部来自**预分配**的 `ActiveList`，回收用 swap-remove，永不扩容；
- 空间网格的格子 Map 复用，只清空内部数组；
- 渲染的面片缓冲、调色板缓存、临时投影点都是复用的，逐帧零分配；
- 帧时间连续偏高时自动把内部分辨率降一档（400→352→320→288），稳定后再升回来。

### 4. 存档

存档只保存"可重建"的信息：随机种子、等级、经验、血量、波次、击杀数、已选加成列表、游玩时长。
读取时重放加成、重建关卡（同一个种子 → 同一套地形），并对所有字段做范围钳制，坏档不会让游戏崩。

## 六、测试

```bash
npm test
```

25 项测试全部通过，覆盖：10 条需求的逐条验证、会话层（暂停/切窗口/存档）、渲染管线（用软件光栅化 Canvas

测试用到的"假 Canvas / 假宿主窗口"让整套逻辑**不需要浏览器**也能验证：

```
tests/engine.spec.ts   需求 1–10：二段跳、技能冷却、AI 前摇、波次、刷怪合法、长跑稳定、存档
tests/session.spec.ts  主循环、切窗口自动暂停 + 3 秒倒计时、节流写档、阵亡清档
tests/render.spec.ts   像素 3D 出图、三种怪主色、连续 30 帧稳定（并导出 tools/.cache/preview-*.png）
tests/ui.spec.ts       HUD / 技能栏 / 各弹窗的渲染断言
```

### 调参

想改手感或难度，基本只需要动两个文件：

- `src/game/config.ts`：玩家移动/跳跃、重力、经验曲线、波次节奏、刷怪上限、相机、特效强度、渲染档位；
- `src/game/content/*.ts`：怪物数值与行为、技能冷却与倍率、升级加成池、波次编排。

改完执行 `npm run build`（或 `npm run dev` 自动重建）即可。

## 七、已知限制

- 结算/选卡/暂停期间**角色也不能移动**（除了波次结算期间允许走动，但禁用一切攻击与伤害）；
- 阵亡后会清掉"进行中的那一局"存档，只保留最佳纪录（否则一读档就继续死循环）；
- 怪会从场地两端进场（不会刷在墙里、不会叠在一起），但玩家站在浮空平台上时，地面怪只能在下面等；
- 移动端没有做虚拟摇杆，建议用键盘游玩；
- `file://` 直接打开时若浏览器禁用本地存储，进度只在本次会话内有效（菜单会提示）。
